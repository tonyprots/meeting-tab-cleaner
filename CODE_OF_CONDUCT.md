# Кодекс поведения

Проект следует [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/):
уважительно к людям, по существу к коду, без оскорблений и давления.

О нарушениях — приватно, через форму
[GitHub Security Advisories](https://github.com/tonyprots/meeting-tab-cleaner/security/advisories/new):
других приватных каналов у GitHub нет, и она подходит и для этого. Жалобы
рассматриваются конфиденциально.
